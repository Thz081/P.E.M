# P.E.M — Monarcas

Importe este repositório na Vercel. Framework: Other. Sem comando de build e sem pasta de saída personalizada. Clique em Deploy.

Esta versão publica o acesso pelo domínio da Vercel e mantém o servidor e a autenticação no portal já publicado. Não é uma migração independente do backend. O servidor atual precisa continuar ativo. Nenhuma matrícula ou senha está no repositório.

Após publicar, teste login, materiais e logout e atualize o QR code do documento com o novo domínio.
